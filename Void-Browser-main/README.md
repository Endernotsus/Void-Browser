Download the zip file:<br>

    - click on download ZIP<br>
    <br>
Install to chrome:<br>
    - Open files app<br>
    - Find the ZIP file<br>
    - Right click <br>
    - Click extract all <br>
    - Go to chrome<br>
    - Click on extentions<br>
    - Go to manage extentions<br>
    - enable developer mode(top Left)<br>
    - click load unpacked<br>
    - Find and click the extracted file<br>
    - Click open<br>
    - Make sure the switch in the corrner is on<br>
    - [Video link for Chrome install](https://google.com)<br>
